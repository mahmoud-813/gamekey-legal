# GameKey — public legal documents

This repository contains the public legal pages for **Cheats for GTA 6: Guide** (iOS app version **1.0.0**), an unofficial game-reference app published by **Mahmoud Hasan**.

- [Privacy Policy](https://mahmoud-813.github.io/gamekey-legal/privacy.html)
- [Terms of Use](https://mahmoud-813.github.io/gamekey-legal/terms.html)
- Support: gamekeyappsupport@gmail.com

These pages are public and readable without logging in. The mobile app source, advertising credentials and service configuration are **not included**.

## Publishing

In GitHub **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**. Public pages need GitHub Pages to be enabled before the links above work.

Only users granted write access to this repository can change its files. The app's offline copies of these policies are versioned separately in its private repository.
